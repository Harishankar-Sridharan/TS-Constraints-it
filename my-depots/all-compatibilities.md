# Tutte le compatibilità

Quando il **Compatibilità con le risorse** viene applicata la restrizione (soprattutto con criteri multipli), questa impostazione ti permette di specificare se **solo una** criterio dall'elenco è sufficiente o se **tutti i criteri** devono essere soddisfatti.

**Formato:** Sì / No

**Esempio:** Tutte le compatibilità - No
